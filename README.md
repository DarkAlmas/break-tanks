# Перерыв: Танки
Откройте `index.html` (или `Перерыв_Танки.html`) двойным кликом в любом браузере — интернет не нужен.
На телефоне: перекиньте файл и откройте в Chrome/Safari.

- WASD/стрелки — движение, мышь — прицел, ЛКМ — огонь по курсору
- **Пробел (ПК)** — удержание = автоогонь + автоприцел на ближайшего (как кнопка ОГОНЬ на телефоне)
- Esc — пауза, M — звук, Enter — рестарт
- Телефон: левая половина экрана — стик движения, правая — прицел+огонь (или кнопка ОГОНЬ с автоприцелом)

## Что нового в v2.1.9
- Дроны **сами подбирают** пикапы. При HP &lt; 45% приоритет ехать за **+** или **◯**.

## Что нового в v2.1.8
- Аптечка **+** тоже лечит дронов (~15 HP). Длительности шаринга ⚡/◯/≫: 3 / 2.5 / 3.5 с (~50%).

## Что нового в v2.1.7
- Подобранные бафы **⚡ / ◯ / ≫** частично передаются дронам (~60% времени). (устарело в 2.1.8: HP тоже шарится.)

## Что нового в v2.1.6

- Щит на старте волны = `perm.shield` (мета ◯), без бесплатного щита.

## Что нового в v2.1

## Что нового в v2
